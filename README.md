# 🛒 BLINKIT DATA ANALYTICS DASHBOARD ON POWER BI

## 📌 Project Overview

The **Blinkit Data Analytics Dashboard** is an interactive Power BI project developed as part of an **IBM Data Visualization Project**.  
This dashboard helps analyze Blinkit's sales performance, outlet efficiency, customer ratings, and product trends through powerful visualizations and business insights.

The project transforms raw sales data into meaningful and interactive reports that support better business decision-making.
